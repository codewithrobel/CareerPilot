# CareerPilot 🚀

CareerPilot is a Spring Boot based backend application for managing:
- User authentication (JWT)
- Job Applications
- Interviews
- Student Dashboard Analytics

## Tech Stack
- Java 17
- Spring Boot 3
- Spring Security (JWT)
- MySQL
- JPA / Hibernate

## Features
- User Registration & Login
- Role Based Access (ADMIN / USER)
- Apply for Interviews
- Track Application Status
- Dashboard Analytics

## Run Locally

1. Create database:
   CREATE DATABASE ai_based;

2. Update application.properties

3. Run:
   mvn spring-boot:run

Server runs on:
http://localhost:9091
